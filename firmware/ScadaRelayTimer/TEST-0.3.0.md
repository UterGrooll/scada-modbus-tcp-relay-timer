# Проверка реле и таймера

Проверка текущего скетча с библиотекой ModbusTCP_RU 0.3.0.
Адрес устройства: `192.168.0.178:502`. В Modbus Poll выбрать TCP/IP, Unit ID 1.
Адреса ниже нулевые. Проверять на безопасной нагрузке.

1. FC04, Address 0, Quantity 3, Scan Rate 1000 ms: состояние реле, оставшиеся секунды и разрешение таймера.
2. FC03, Address 0, Quantity 1: уставка времени.
3. FC06, Address 0, Value 10. Прочитать FC03: должно вернуться 10.
4. FC05, Address 1, ON: разрешить таймер. FC05, Address 0, ON: включить реле.
5. Проверить отсчёт и выключение примерно через 10 секунд.
6. FC05, Address 1, OFF: отключить таймер. Включить реле и проверить, что через 10 секунд оно остаётся включённым. Выключить через Coil 0.
7. Отключить кабель, затем подключить обратно. Проверить переподключение Modbus Poll и работу таймера без сети.
8. Отключить и включить питание: уставка и разрешение таймера должны сохраниться, реле должно стартовать выключенным.
9. Вернуть рабочую уставку и нужный режим таймера.

## Особенности текущего скетча

- Диапазон времени: 1..3600 секунд, по умолчанию 300. Значения вне диапазона ограничиваются.
- Повторная запись ON в Coil 1 при работающем реле запускает отсчёт заново.
- Изменение Holding Register 0 меняет длительность относительно текущего момента запуска реле.
- Через 420 секунд после включения реле выполняется аппаратный сброс Ethernet через D3. Ручное выключение реле не отменяет этот запланированный сброс.
- При статусе Unknown выполняется переинициализация Ethernet каждые 30 секунд.
- Аппаратный watchdog AVR в этом скетче не включён; используется проверка состояния Ethernet.

При ошибке записать модель платы и Ethernet-чипа, FC/Address/Quantity, число клиентов, текст ошибки и время восстановления связи.
